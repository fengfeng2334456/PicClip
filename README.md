# ICO Icon Maker - Online Image to ICO Converter

A free, browser-based tool to convert images (PNG, JPG, GIF, WEBP) to ICO icon format. Supports multiple sizes generation for Windows applications and website favicons.

![ICO Icon Maker Screenshot](screenshot.png)

## Features

- **Multi-format Support**: Convert PNG, JPG, GIF, JPEG, WEBP to ICO
- **Multiple Sizes**: Generate icons in 16×16, 32×32, 48×48, 64×64, 96×96, 128×128, 256×256, 512×512
- **Pure Frontend**: All processing happens in your browser - no server upload needed
- **Bilingual**: Supports English and Chinese (中文)
- **Drag & Drop**: Easy image upload with drag and drop support
- **Batch Download**: Download all generated icons at once

## Demo

Open `index.html` in your browser or visit the online demo.

## Usage

1. **Upload Image**: Click the upload area or drag and drop an image
2. **Select Sizes**: Choose one or more icon sizes (default: 256×256)
3. **Generate**: Click "Generate ICO Icon" button
4. **Download**: Click individual icons or "Download All"

## Technical Details

### Pure Browser Processing
- No backend server required
- Images are processed locally using Canvas API
- ICO file format is generated using JavaScript ArrayBuffer manipulation

# ICO图标制作 - 在线图片转ICO工具

免费的浏览器端工具，将图片（PNG、JPG、GIF、WEBP）转换为ICO图标格式。支持多尺寸生成，适用于Windows应用程序和网站favicon。

- **多格式支持**: PNG、JPG、GIF、JPEG、WEBP 转 ICO
- **多尺寸生成**: 16×16 到 512×512 共8种尺寸

- **中英双语**: 支持英文和中文切换
- **拖拽上传**: 支持点击上传和拖拽上传
- **批量下载**: 一键下载所有生成的图标

## 使用方法

1. **上传图片**: 点击上传区域或拖拽图片

3. **生成图标**: 点击"生成ICO图标"按钮
